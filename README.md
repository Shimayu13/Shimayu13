## 🚀 主な研究・開発プロジェクト

### 🚆 Railocation
**センサを用いた移動体内部での位置推定システム**

走行中の鉄道車両内で、乗客の位置を推定するシステムの研究・開発に取り組んでいます。

- BLEを利用したセンサデータの無線通信
- 複数センサの情報を統合した位置推定のシステム開発
- iOSアプリケーションとの連携

### 📡 UWBウォークスルー改札システム
**UWBを活用した非接触型改札システム**

利用者が立ち止まらずに通過できる次世代型改札システムのプロトタイプを開発しています。

- UWBによる距離・方向推定
- ESP32を用いた組み込み制御
- FeliCa・QRコードによる認証
- iPhoneアプリケーションとの連携

### 🖥️ 鉄道運行情報システム
**鉄道の運行情報を取得・可視化するシステム**

鉄道の運行情報を活用したWebアプリケーションやDiscord Botを開発しています。

- 鉄道運行情報の取得・解析
- Next.jsを使用したWebアプリケーション開発
- Discord Botによる情報配信
- 列車位置・運行状況の可視化

### 📱 iOSアプリケーション開発

Swift・SwiftUIを使用したiPhone・Apple Watch向けアプリケーションを開発しています。

- センサデータの取得・可視化
- BLEによる外部デバイス連携
- Apple Watchとの連携
- NFC・QRコードを活用したアプリケーション
